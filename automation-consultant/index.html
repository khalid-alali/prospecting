Standard cases and edge cases

Most of the time in an operations workflow is the same path, repeated. A smaller set of cases needs a person.

  • Map the path people walk every day, including the tab they open to look something up
  • Put AI and rules on the standard case so it moves without a handoff
  • Send the edge case to a named person, with the external record already attached
  • Leave the systems you already run in place and connect them

Where this gets built

One place this shows up is the help desk. The ticket is missing the order, the account, or the entitlement that lives in another system. I integrate that data and, in Zendesk, build the app that puts it on the ticket. Help desk automation is that build. Customer operations is the broader support work.
